# LSP-P3

## CARA CLONE REPOSITORY GITHUB MELALUI TERMINAL

### 1. Clone Repository GitHub

Masukkan perintah berikut untuk mengunduh repository GitHub milik kamu.

```bash
git clone https://github.com/annisanuraulia-codeer-commits/LSP-P3
```

### 2. Melihat Isi Direktori

Setelah proses clone selesai, gunakan perintah `ls` untuk melihat folder repository yang berhasil diunduh.

```bash
ls
```

### 3. Masuk ke Direktori Repository

Masuk ke folder `LSP-P3` menggunakan perintah berikut.

```bash
cd /home/nisa/LSP-P3/
```

### 4. Membuka File Dokumentasi

Buka file dokumentasi instalasi dan konfigurasi MariaDB menggunakan Nano.

```bash
nano "A. INSTALASI DAN KONFIGURASI DATABASE MARIADB.md"
```
